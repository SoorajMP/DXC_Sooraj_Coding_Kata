# DXC_Sooraj_Coding_Kata
DXC  Coding Test Repo.

- Application is using JDK 21 version
- It is using H2 inmemory db to storing records.
- It is using Swagger documentation 
- Enabled the versioning 

## Access the application using below Swagger URL 
Swagger UI: http://localhost:8080/swagger-ui.html

Application URL : http://localhost:8080

## How to run the applicaiton

This application is using Java 21 . 

### Using Maven command and Jar
```bash 
mvn clean install
java -jar <<jar file in target folder`
```

### Using IntelliJ IDE

- Open the application in IntelliJ IDEA.
- Open Project Folder.
- Click **Run** Configure the application in JDK 21 .
- Open the Swagger UI in a browser.

### Run using spring-boot goal
```bash
mvn spring-boot:run
```
